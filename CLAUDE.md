# Documentation Pyramid

## Brief

The documentation pyramid aims to solve the problem of discoverability of all important facets of a software product's implementation.
For agents and human readers at the same time.

This repository contains fixtures, an explanatory README, and additional tools to help people set up and configure their own documentation pyramid fo their own software projects.

## Content

Because of the proliferation of different agentic development workflows, the main way to install this is for users to point their LLMs to the repository's README file.

Which is also what people see when they visit the projects GitHub page.

Files & directories: 

README.md:      - Abstract and installation instructions
/references/    - reference files for the implementing agent
