# Glossary

The project's domain words, defined once, in the language the team, the docs and the code share. Think Domain Driven Design -> ubiquitous language. Covers the business domain, and only that; no general programming terms. One sentence per definition. Notes stay empty unless a disambiguation matters. Alphabetical.
